# AmazingMaze3D

A 3D maze game built with C# and OpenTK. Explore textured maze levels, use a
flashlight, avoid enemies, and discover teleporters.

## Running

Requires the .NET 9 SDK.

```bash
dotnet run
```

WASD moves the player, the mouse controls the camera, **Shift** runs, **F**
toggles the flashlight, and **E** activates teleporters. A map can be selected
by passing its filename, for example `dotnet run -- map2.txt`.
